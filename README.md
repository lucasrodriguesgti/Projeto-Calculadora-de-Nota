# Calculadora de Média do Aluno

## 1. Título e Descrição

Sistema desenvolvido em Python para calcular a média de duas notas de um aluno e informar se ele foi aprovado ou reprovado.

O sistema considera o aluno aprovado quando a média é maior ou igual a 7,0.
